prelixOS

UI piszesz w HTML.
To system operacyjny.

Opisujesz interfejs zwykłymi tagami — prelixOS wyrenderuje go prosto na ekranie. Tagi, kolory, układ: dokładnie tak, jak to napiszesz. Twój markup staje się pulpitem.

Zobacz kod Jak to wygląda ↓
HTML →
ekran.

Nie ma po drodze silnika przeglądarki ani frameworka. Markup wchodzi, piksele wychodzą.

Renderer Własny silnik HTML/CSS zbudowany od zera w Ruście.
przykład 
<div class="okno">
  <span>prelixOS</span>
</div>

.okno { display: flex; background-color: #ffd23c;
        padding: 10px 20%; border: 4px solid #2c2a8c; }

→ i to już jest okno aplikacji na pulpicie systemu
Szybka pętla Zmieniasz markup — efekt na ekranie w sekundy, nie w minuty.
🧱

Deklaratywne UI

Opisujesz wygląd w HTML i CSS, system sam liczy układ, kolory i każdy piksel ekranu.

🪶

Lekki rdzeń

System chodzi bez ciężkich silników graficznych — szybki start, niskie wymagania.

🌅

Wschód słońca

Interfejs systemu rodzi się od nowa co render — jak poranek, tylko szybciej.

Co dalej?

Następny przystanek: kliknięcia i klawiatura płyną z HTML-a prosto do systemu. Potem obrazki, selektory klas i ładniejsza typografia.
