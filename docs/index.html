UI piszesz w HTML.
To system operacyjny.

prelixOS wyrenderuje Twój HTML prosto na ekranie — tagi, kolory, układ, wszystko dokładnie tak, jak to opiszesz. Bez przeglądarki, bez zbędnej machinerii: twój markup staje się pulpitem.

Zobacz kod Jak to wygląda ↓ 
<div class="okno">
  <span>prelixOS</span>
</div>

.okno { display: flex; background-color: #ffd23c;
        padding: 10px 20%; border: 4px solid #2c2a7a; }

→ i to już jest okno aplikacji na pulpicie systemu
🌅

Deklaratywne UI

Opisujesz wygląd w HTML i CSS, system sam liczy układ, kolory i każdy piksel ekranu.

📐

Layout jak w CSS

Flex, padding, margin, jednostki px i % — wszystko, co znasz ze stron, działa w aplikacjach.

🪶

Lekki rdzeń

System chodzi bez ciężkich silników graficznych — szybki start, niskie wymagania.

⚡

Natychmiastowa pętla

Zmieniasz markup i widzisz efekt na ekranie w sekundy — bez przebudowywania świata.

Co dalej?

Następny przystanek: kliknięcia i klawiatura płyną z HTML-a prosto do systemu. Potem obrazki, selektory klas i ładniejsze typografia.
