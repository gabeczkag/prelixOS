Frontend w HTML.
Backend w Rust.

prelixOS to system operacyjny, w którym interfejs opisujesz zwykłym HTML-em, a cały silnik — parser, layout, rasteryzacja — działa w Rust prosto na framebufferze. Bez przeglądarki, bez JS — tylko deklaratywne UI.

Zobacz kod Jak to działa ↓ 
// stronie udajesz layout, system resztę — prelix-render, ~no_std
<div class="okno">
  <span>prelixOS</span>
</div>

.okno { display: flex; background-color: #7a3cff;
        padding: 10px 20%; border: 4px solid #000; }

$ ./run.sh   →  HTML wyrenderowany prosto na framebuffer w QEMU
⚙️

no_std od rdzenia

Cały renderer kompiluje się bez biblioteki standardowej — ten sam kod działa w kernelu i na Linuksie.

📐

Flexbox na taffy

Layout liczony silnikiem taffy: flex-direction, padding, margin, jednostki px i % — tak jak w CSS.

🖌️

Piksele w tiny-skia

Prostokąty, bordery i tekst rasteryzowany fontdue wprost do bufora pikseli, bez GPU i bez shapingu.

⚡

Iteracja po hoście

Na Linuksie renderer zapisuje wynik do PNG w sekundy — reboot QEMU tylko wtedy, gdy musisz.

Co dalej?

Następny przystanek: zdarzenia — kliknięcia i klawiatura przechodzą z HTML-a do Rust backendu. Potem obrazki, selektory klas i skalowanie fontów.
